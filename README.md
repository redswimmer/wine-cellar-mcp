# wine-cellar-mcp

An MCP server that lets an AI agent remember which wines you like. Built for a
NemoClaw (OpenClaw) agent that you talk to in Telegram, running on AWS
serverless (API Gateway, Lambda, DynamoDB).

- Design: [docs/DESIGN.md](docs/DESIGN.md)
- Deploying: [docs/DEPLOY.md](docs/DEPLOY.md)

## Develop

```
uv sync
uv run ruff check . && uv run ruff format --check .
uv run ty check
uv run pytest
```

## Users

Each user gets their own API token, which decides whose wines a request reads
and writes; tools never take a user ID. User IDs are generated by the server
(`usr_<ulid>`), and each user has a unique username. Add a user and get their first token with
`uv run wine-tokens --stage dev add-user --username <username> --label <where-used>`.

## Tools

| Tool | What it does |
| --- | --- |
| `create_wine` | Record a wine and your opinion (only the name is required) |
| `update_wine` | Change a wine, e.g. a new verdict or more notes |
| `search_wines` | Search by text, a label photo, or both |
| `list_wines` | List with filters (verdict, varietal, created/updated dates), paged with `next_token` |
| `get_wine` | One wine |
| `delete_wine` | Remove a wine |
| `add_photo` | Get a link to upload a label photo to a wine |
| `delete_photo` | Remove a photo from a wine |
| `upload_search_photo` | Get a link to upload a photo to search with |
